## النشر المجاني باستخدام GitHub Pages
1. أنشئ حساباً في GitHub إذا لم يكن لديك حساب.
2. أنشئ مستودعاً جديداً باسم `wtr-social-links`.
3. ارفع `index.html` ومجلد `assets` إلى المستودع.
4. افتح Settings ثم Pages.
5. من Build and deployment اختر Deploy from a branch.
6. اختر الفرع `main` والمجلد `/ (root)` ثم Save.
7. انتظر حتى يظهر رابط الصفحة، ويكون غالباً بالشكل:
   `https://USERNAME.github.io/wtr-social-links/`

## إنشاء QR Code
بعد نشر الصفحة والحصول على رابطها النهائي، أنشئ QR Code باستخدام الرابط نفسه.
لا تنشئ الرمز قبل النشر، لأن الرابط النهائي لم يتحدد بعد.
